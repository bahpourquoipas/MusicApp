      Google Drive

      Disponible uniquement si l'application est hébergée en https (GitHub Pages, par exemple).

      Pourquoi, et que faire en attendant ?

      Google refuse la connexion depuis un fichier ouvert en local. Exporter et Importer ci-dessus fonctionnent déjà avec Drive : sur mobile, le sélecteur de fichiers propose Google Drive si l'application Drive est installée.

      À créer une seule fois sur console.cloud.google.com : nouveau projet → API Google Drive → identifiants → ID client OAuth (type « Application Web ») → ajoutez l'adresse de votre site dans « Origines JavaScript autorisées ».

      Aide

      Écrire une chanson

      • Accords : [Am] juste avant la syllabe concernée, ou une ligne d'accords seule au-dessus des paroles (grilles collées depuis le web).
      • Couleur : {rouge:texte} ou {#ff8800:texte}. Noms disponibles : rouge, bleu, vert, jaune, orange, violet, rose, blanc, gris.
      • Repère de section : une ligne seule {c: Refrain}.
      • Une ligne qui commence par # est un commentaire, invisible sur scène.

      Au prompteur

      • Espace démarre ou arrête le défilement (le texte se met en mouvement tout de suite).
      • ← → chanson précédente ou suivante, ↑ ↓ défilement à la main.
      • F plein écran, Échap retour à la bibliothèque.
      • Une pédale Bluetooth qui envoie ces touches fonctionne sans réglage.
      • Capo − / + transpose en direct de −12 à +12 demi-tons, sans modifier le texte enregistré. Renseignez la tonalité d'origine pour obtenir une suggestion de capodastre.

      Bibliothèque

      • La recherche porte sur le titre, l'artiste, le style, les chanteurs, la tonalité et les instruments (plusieurs mots possibles). Dans une playlist, elle montre aussi les chansons qui n'y sont pas encore.
      • Sélectionner permet d'ajouter, retirer, supprimer ou imprimer plusieurs chansons d'un coup.
      • Dans une playlist, touchez le numéro d'une chanson pour la déplacer directement à une autre position.
      • Une suppression peut être annulée pendant quelques secondes.

      Sauvegarde

      • Les données restent dans ce navigateur : exportez-les régulièrement depuis les Réglages (.json). Les fichiers EasyZic (.ezp) et ChordPro (.cho, .pro, .txt) peuvent être importés.
