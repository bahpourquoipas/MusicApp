            Équipe

            Partager des sets avec le groupe, par la base Supabase du groupe (gratuite).

            Vous rejoignez l'équipe d'un autre musicien ? Ouvrez simplement son invitation (lien ou QR code : Réglages → Coller un lien, ou Scanner un QR code) : tout se remplit, il ne reste qu'à indiquer votre prénom. Ce qui suit ne concerne que le musicien qui crée l'équipe, une seule fois.

            1 · Créer le projet Supabase
            1. Sur supabase.com : Start your project, puis créez un compte gratuit (plan Free ; les conditions exactes sont sur supabase.com/pricing).
            2. New project : un nom (celui du groupe, par exemple), un mot de passe de base de données (MusicApp n'en a pas besoin : gardez-le simplement) et une région en Europe. Patientez environ deux minutes.
            3. Dans le projet, cliquez sur Connect (en haut) : vous y trouvez l'adresse du projet (Project URL) et la clé Publishable key (sb_publishable_…). Elles sont aussi dans Project Settings → API Keys.

            Attention : n'utilisez jamais la clé secret (sb_secret_…, ou service_role) : elle donne tous les droits sur le projet. MusicApp la refuse.

            Un projet gratuit resté une semaine sans aucune activité est mis en pause par Supabase ; il se reprend en un clic dans le tableau de bord. Un envoi ou une lecture de temps en temps suffit à l'éviter.

                      Aide
                      
    
                      
      
                      Écrire une chanson
                      
      
                        
        
                      • Accords : [Am] juste avant la syllabe concernée, ou une ligne d'accords seule au-dessus des paroles (grilles collées depuis le web).
                        • 
        
                      • Couleur : {rouge:texte} ou {#ff8800:texte}. Noms disponibles : rouge, bleu, vert, jaune, orange, violet, rose, blanc, gris.
                        • 
        
                      • Repère de section : une ligne seule {c: Refrain}.
                        • 
        
                      • Une ligne qui commence par # est un commentaire, invisible sur scène.
                        • 
      
                      
      
                      Chansons copiées d'un site web (boiteachansons.net…)
                      
      
                        
        
                      • Collez la chanson dans l'éditeur. Quand les accords sont alignés au-dessus des paroles, elle s'affiche telle quelle (G2, D4, C2, Em/F#… sont compris).
                        • 
        
                      • Quand l'appli reconnaît une grille de site à ranger, un message propose Convertir ; le bouton Convertir de l'éditeur (groupe « Grille web ») fait la même chose à tout moment. Une ligne comme Intro : : G G2 G devient un repère {c: Intro} suivi de sa grille ; un titre seul ([Refrain], Couplet 1 :) devient un repère.
                        • 
        
                      • Les sites écrasent souvent les espaces qui plaçaient chaque accord : G G G2 G se retrouve collé au début de « Mon enfant nue sur les galets ». Convertir répartit alors ces accords à égale distance sur la ligne, entre crochets. C'est une estimation : la copie ne dit plus sur quelle syllabe tombe chaque accord, à vous de la vérifier à l'oreille et de déplacer un [accord] si besoin.
                        • 
        
                      • Rien ne change sans votre accord : le message Annuler rétablit le texte, les lignes déjà alignées ne sont jamais touchées, et convertir une deuxième fois ne change rien de plus.
                        • 
      
                      
      
                      Accords cliquables
                      
      
                        
        
                      • Au prompteur comme dans l'aperçu de l'éditeur, touchez un accord (Am7, D/F#, G(sus4)…) : une fenêtre affiche son doigté à la guitare (grille, doigts, barré, plusieurs positions) ou au piano (touches à jouer, basse d'un accord renversé). Elle propose aussi tous les accords de la chanson, pour passer de l'un à l'autre.
                        • 
        
                      • Les doigtés sont calculés à partir des notes de l'accord et vérifiés : la note la plus grave est la fondamentale (ou la basse indiquée). Ce sont des propositions faciles à jouer ; d'autres existent.
                        • 
        
                      • Notations françaises comprises : A4 = La sus4, F2 = Fa sus2, G7M = Sol septième majeure, C+ = Do augmenté.
                        • 
        
                      • Toucher un accord met le défilement en pause. Pour désactiver ce comportement (scène, tablette tenue à la main) : Réglages → Prompteur.
                        • 
      
                      
      
                      Partager une fiche avec un autre musicien
                      
      
                        
        
                      • L'icône QR code (au prompteur, dans la liste, ou dans le menu ⋯ d'une chanson) affiche un QR code et un lien : titre, artiste, tonalité, tempo, mesure, paroles et accords, et les liens d'écoute enregistrés. Tout est fabriqué sur l'appareil, sans Internet ni service en ligne. Votre transposition personnelle n'est pas transmise.
                        • 
        
                      • Sur l'autre tablette ou téléphone, ouvrez l'appareil photo et visez le code : quand l'appli est hébergée en https, MusicApp s'ouvre et propose la fiche. Rien n'est ajouté sans accord ; si une chanson de même titre existe déjà, vous choisissez entre la remplacer et en garder une copie.
                        • 
        
                      • Le lien, lui, se copie ou s'envoie (message, AirDrop…). Le destinataire peut aussi le coller dans Réglages → Coller un lien.
                        • 
        
                      • Si l'appli est ouverte depuis un fichier, le code ne contient que la fiche : il se lit avec Réglages → Scanner un QR code (réservé aux navigateurs qui savent lire les QR codes, comme Chrome sur Android ; l'appareil photo ordinaire n'afficherait que du texte). Indiquer l'adresse publique de MusicApp dans les Réglages ou dans la fenêtre de partage donne un code que l'appareil photo ouvre directement.
                        • 
        
                      • Une fiche très longue ne tient pas toujours dans un QR code : le lien reste alors disponible. Plus le code est dense, plus il faut le présenter de près, écran bien lumineux.
                        • 
        
                      • iPad / iPhone : si MusicApp est installée sur l'écran d'accueil, l'appareil photo ouvre le lien dans Safari, dont les données sont séparées de celles de l'icône. Copiez alors le lien (appui long) et collez-le dans l'appli de l'écran d'accueil : Réglages → Coller un lien.
                        • 
      
                      
      
                      Écouter un titre : Spotify et Apple Music
                      
      
                        
        
                      • L'icône casque (dans la liste, dans le menu ⋯ d'une chanson ou dans l'éditeur) ouvre une fenêtre avec une ligne par service. Tant qu'aucun lien n'est enregistré, le bouton lance la recherche du titre et de l'artiste sur Spotify ou Apple Music : dans l'appli du service si elle est installée, sinon dans le navigateur.
                        • 
        
                      • Pour aller droit au bon titre : dans Spotify ou Apple Music, Partager → Copier le lien, puis collez-le dans le champ de la fenêtre. Le lien exact est enregistré avec la chanson (le casque devient ambre) et le bouton l'ouvre directement. Les deux adresses peuvent être collées d'un coup ; un message « Annuler » ou la croix retire un lien.
                        • 
        
                      • Le lien enregistré suit la chanson : copie, fusion de doublons, sauvegarde, set partagé en fichier, QR code et lien de partage. À la réception, il complète vos liens sans jamais en effacer.
                        • 
        
                      • MusicApp ne se connecte à aucun de ces services et ne leur envoie rien tant que vous ne touchez pas un lien. Seules les adresses de titre, d'album, d'artiste ou de playlist de Spotify et d'Apple Music sont acceptées. Sans réseau, les boutons n'aboutissent pas, mais les liens restent enregistrés.
                        • 
      
                      
      
                      Écouter toute la setlist : playlist Spotify et Apple Music
                      
      
                        
        
                      • Dans une playlist ouverte, l'icône casque à côté de son nom (ou Outils → Écouter cette playlist) ouvre « Écouter la setlist » : une carte Spotify, une carte Apple Music et la liste des titres, un par un, dans l'ordre du set. Un titre s'ouvre sur son lien exact quand la fiche en garde un (voir ci-dessus), sinon sur une recherche.
                        • 
        
                      • Spotify, sans compte ni réglage : Copier N liens place les adresses des titres dans le presse-papiers ; dans l'appli Spotify pour ordinateur, ouvrez une playlist, cliquez dans la liste des titres et collez (Ctrl+V ou ⌘V). Ce raccourci de Spotify marche le plus souvent, mais Spotify ne le garantit pas.
                        • 
        
                      • Apple Music : Apple ne laisse pas une appli créer une playlist sans un compte développeur payant. Le plus simple : Copier la liste « Artiste - Titre » ou Télécharger en CSV, puis un service de transfert de playlists (TuneMyMusic, Soundiiz…) qui crée la playlist dans Apple Music. Vérifiez ensuite chaque titre : la reconnaissance se fait sur le titre et l'artiste.
                        • 
        
                      • Une fois la playlist créée, collez son lien (Partager → Copier le lien) dans le champ de la fenêtre : il est gardé avec la setlist (le casque de la playlist devient ambre, le bouton « Ouvrir » y mène) et voyage avec le fichier de la playlist et la sauvegarde. Une playlist dupliquée n'hérite pas de ce lien.
                        • 
        
                      • Créer la playlist directement sur Spotify (option avancée) : le bouton Créer la playlist sur Spotify… l'ajoute à votre compte. Spotify ne l'autorise qu'avec une appli développeur à votre nom (gratuite, mais son propriétaire doit avoir un abonnement Premium) : l'assistant vous guide, vous déclarez l'adresse de redirection qu'il affiche et vous collez le « Client ID » de l'appli (ce n'est pas un secret). MusicApp doit être ouverte depuis une adresse https:// (GitHub Pages par exemple).
                        • 
        
                      • La connexion se fait sur la page de Spotify : aucun mot de passe ne passe par MusicApp. Les jetons de connexion restent sur cet appareil, jamais dans les sauvegardes, les partages ni Google Drive ; Se déconnecter les efface. L'appli cherche ensuite chaque titre et affiche un écran de vérification : vous voyez la version choisie, vous décochez ce qui ne convient pas, et rien n'est créé avant votre accord. Vous pouvez fermer la fenêtre pendant la création.
                        • 
        
                      • Limites : une appli Spotify en « mode développement » n'accepte que quelques comptes déclarés, et Spotify peut la refuser (erreur 403) : l'appli l'explique alors, et les deux chemins sans compte restent disponibles. Sans réseau rien de tout cela ne fonctionne, mais les liens enregistrés restent là.
                        • 
      
                      
      
                      Tempo, métronome et décompte
                      
      
                        
        
                      • Dans l'éditeur, renseignez le tempo (BPM) et la mesure (4/4, 3/4, 6/8…). « Frapper » mesure le tempo à la volée : tapez en rythme quatre fois ou plus. « Écouter » joue le clic.
                        • 
        
                      • Au prompteur, le bouton métronome (à gauche de précédent / lecture / suivant) ouvre les réglages : décompte d'une mesure avant le départ (visuel, sonore ou les deux), puis pulseur ambre dans le coin de l'écran et/ou clic pendant le morceau.
                        • 
        
                      • Avec un décompte, le texte démarre exactement sur le premier temps qui suit la mesure de décompte. Un toucher sur le texte, Espace ou « précédente / suivante » annule le décompte.
                        • 
        
                      • Sans tempo renseigné pour une chanson, elle démarre tout de suite, sans décompte ni pulseur.
                        • 
      
                      
      
                      Tonalité et tempo en série
                      
      
                        
        
                      • Dans l'éditeur, Détecter propose la tonalité d'après les accords de la chanson (le plus souvent la bonne, mais c'est une estimation : la tonalité relative, par exemple Do et La mineur, se confond facilement). Le bouton « Plutôt … » bascule sur l'autre possibilité.
                        • 
        
                      • Pour une bibliothèque entière, le bouton Outils de la bibliothèque (ou le message « Compléter les fiches ») ouvre un assistant. Onglet Tonalités : une proposition par chanson, à valider d'un geste, avec les premiers accords pour vérifier ; vous pouvez corriger la tonalité dans la ligne même. Onglet Tempos : la chanson s'affiche, vous frappez le rythme (sur le grand bouton ou avec la barre Espace), puis « Enregistrer et suivant ». « ÷ 2 » et « × 2 » corrigent un tempo frappé deux fois trop vite ou trop lentement ; « Écouter » joue le clic pour vérifier.
                        • 
        
                      • Les changements sont enregistrés au fil de l'eau et le message « Annuler » défait une validation de tonalités.
                        • 
      
                      
      
                      Repères de section
                      
      
                        
        
                      • Une fiche qui contient au moins deux repères (Intro, Couplet 1, Refrain, Pont…) affiche au prompteur une barre de parties au-dessus du texte, un bouton par partie. Un toucher amène la partie en haut de l'écran ; le défilement automatique continue. La partie en cours est marquée au fil du texte.
                        • 
        
                      • Au clavier ou à la pédale : Maj + ↑ / ↓ (ou [ / ]) pour la partie précédente ou suivante, 1 à 9 pour aller directement à la partie n° 1 à 9 (sur un clavier AZERTY, pas besoin de Maj). La barre se masque dans Réglages → Prompteur ; les touches fonctionnent quand même.
                        • 
        
                      • Sont des repères : la ligne {c: Refrain}, mais aussi une ligne qui ne contient que le mot (Refrain, [Refrain], Couplet 2 :, Pont, Intro…) et les titres colorés des fiches importées d'EasyZic. Vos fiches existantes en profitent sans retouche.
                        • 
        
                      • Pour les fiches qui n'en ont pas : Repères auto dans l'éditeur, ou Outils → Repères de section pour toute la bibliothèque (ou la playlist ouverte). L'appli cherche un bloc de paroles qui se répète, séparé par des lignes vides : c'est le refrain ; les autres blocs sont des couplets ; une grille sans paroles au début est l'intro, à la fin l'outro, au milieu un instrumental. « Voir » montre où chaque repère se placerait. Rien n'est écrit avant votre validation, seules des lignes {c: …} sont ajoutées (paroles et accords ne bougent pas) et le message « Annuler » les retire.
                        • 
        
                      • Ce sont des propositions, pas une analyse musicale : l'appli ne devine ni pont ni pré-refrain, et ne propose rien quand aucun refrain ne se répète. Ces repères-là s'ajoutent à la main, avec {c: Pont} dans l'éditeur.
                        • 
      
                      
      
                      Au prompteur
                      
      
                        
        
                      • Espace démarre ou arrête le défilement (le texte se met en mouvement tout de suite).
                        • 
        
                      • ← → chanson précédente ou suivante, ↑ ↓ défilement à la main.
                        • 
        
                      • Maj + ↑ / ↓ (ou [ / ]) partie précédente ou suivante, 1 à 9 saut direct à la partie n° 1 à 9 : voir « Repères de section ».
                        • 
        
                      • Page ↓ Page ↑ défilement d'un écran (pédales tourne-pages).
                        • 
        
                      • F plein écran, Échap retour à la bibliothèque.
                        • 
        
                      • Une pédale Bluetooth qui envoie ces touches fonctionne sans réglage.
                        • 
        
                      • Précédente / Suivante (de part et d'autre du bouton de lecture) suivent la liste affichée : l'ordre de la playlist ouverte, ou la bibliothèque telle que vous l'avez triée ou filtrée. Le numéro, en haut, indique votre place dans la liste.
                        • 
        
                      • Plein écran sur tablette : sur iPad, le système peut quitter le plein écran pendant un défilement au doigt ; un bouton « Rétablir » apparaît alors. Pour un plein écran sans aucune interruption, ajoutez l'application à l'écran d'accueil (Safari : Partager → Sur l'écran d'accueil), elle s'ouvre ensuite sans barre de navigateur.
                        • 
        
                      • Vitesse − / + : 10 crans, chacun 25 % plus rapide que le précédent. Le cran 5 convient à une chanson moyenne (environ 4 minutes) ; la vitesse suit la taille du texte, donc agrandir les caractères ne change pas la durée du défilement.
                        • 
        
                      • Capo − / + transpose en direct de −12 à +12 demi-tons, sans modifier le texte enregistré. Renseignez la tonalité d'origine pour obtenir une suggestion de capodastre.
                        • 
      
                      
      
                      Bibliothèque
                      
      
                        
        
                      • La recherche porte sur le titre, l'artiste, le style, les chanteurs, la tonalité et les instruments (plusieurs mots possibles). Dans une playlist, elle montre aussi les chansons qui n'y sont pas encore.
                        • 
        
                      • Sélectionner permet d'ajouter, retirer, supprimer ou imprimer plusieurs chansons d'un coup. Chaque chanson cochée porte un numéro : l'ordre des coches est l'ordre dans lequel elles seront ajoutées.
                        • 
        
                      • Dans une playlist, trois façons de réordonner : glisser-déposer (attrapez la poignée ⋮⋮ à gauche de la chanson, à la souris, au doigt ou au stylet, faites-la monter ou descendre puis relâchez ; la liste défile toute seule près du bord, Échap annule), les flèches haut / bas, ou le numéro de la chanson pour la placer directement à une autre position. Un message « Annuler » défait le glisser-déposer.
                        • 
        
                      • Une suppression peut être annulée pendant quelques secondes.
                        • 
      
                      
      
                      Préparer un set
                      
      
                        
        
                      • Nouvelle playlist depuis une sélection : cochez les chansons dans l'ordre où vous voulez les jouer, puis « Nouvelle playlist ». Le set reprend l'ordre des coches ; un message « Annuler » la supprime.
                        • 
        
                      • Dupliquer une playlist (icône de copie à côté de son nom, ou Outils → Dupliquer cette playlist) pour préparer une variante, par exemple une version courte : mêmes chansons, même ordre, mêmes réglages de durée. L'original n'est pas touché.
                        • 
        
                      • Durée du set : dans une playlist ouverte, la ligne sous le titre donne la durée totale, l'heure de fin si vous avez indiqué l'heure de début, et l'écart avec votre objectif. Touchez-la (ou Outils → Durée du set) pour régler la pause entre deux titres, l'objectif et l'heure de début, et saisir les durées titre par titre (Entrée passe au suivant).
                        • 
        
                      • Une chanson sans durée saisie est estimée d'après ses paroles : un « ≈ » signale que le total contient des estimations. Dès que trois chansons ont une vraie durée, l'estimation se cale sur elles. La durée s'écrit « 3:45 », « 3 min 45 » ou « 225 s », dans l'éditeur ou dans la fenêtre du set ; elle suit la chanson (copie, partage, fusion).
                        • 
        
                      • Doublons : Outils → Chercher les doublons. Une pastille « Doublon ? » apparaît sur les fiches qui se ressemblent (même titre, titres presque identiques, paroles presque identiques ; « Deux fois ? » quand une playlist contient les deux). Vous cochez la fiche à garder : elle complète ses champs vides avec ceux des autres et prend leur place dans les playlists. Rien n'est jamais fusionné tout seul, et une fusion s'annule. « Ce ne sont pas des doublons » écarte une paire (par exemple une version avec capo voulue).
                        • 
      
                      
      
                      Partager un set entier
                      
      
                        
        
                      • Un set ne tient pas dans un QR code : il voyage dans un fichier. Ouvrez la playlist, puis touchez l'icône de partage à côté de son nom (ou Outils → Partager cette playlist). Envoyer… ouvre le menu de partage de l'appareil (AirDrop, Messages, e-mail…) ; Télécharger le fichier l'enregistre, pour l'envoyer par le moyen de votre choix.
                        • 
        
                      • Le fichier contient les titres dans l'ordre du set : paroles, accords, tonalité, tempo, mesure, durée et liens d'écoute, avec la pause entre les titres, l'objectif et l'heure de début. Votre transposition et vos vitesses de défilement restent chez vous.
                        • 
        
                      • Pour la recevoir : enregistrer le fichier sur l'appareil (iPhone, iPad : « Enregistrer dans Fichiers »), puis, dans MusicApp, Outils → Recevoir une playlist (ou Réglages → Importer) et choisir le fichier. Un aperçu montre ce qui est nouveau, ce qui existe déjà et ce qui diffère ; rien n'est ajouté avant votre accord, et « Annuler » défait tout l'import.
                        • 
        
                      • Quand une chanson du set existe déjà chez vous avec un texte différent, vous choisissez : garder la vôtre (par défaut), la mettre à jour avec la version reçue (titre, transposition et vitesse restent les vôtres) ou garder les deux. Pour une seule chanson, le QR code ou le lien de la fiche suffit.
                        • 
      
                      
      
                      Équipe : partager les sets avec le groupe (facultatif)
                      
      
                        
        
                      • Pour un groupe qui se passe souvent des sets, MusicApp peut les déposer dans une base Supabase gratuite qui appartient au groupe : un musicien envoie un set, les autres le récupèrent, avec le même aperçu que pour un fichier. MusicApp n'a aucun serveur à lui. Sans cette option, rien ne change et l'appli ne contacte jamais Supabase.
                        • 
        
                      • Rien ne part et rien ne se synchronise tout seul. Un set est envoyé quand vous touchez « Envoyer », la liste est lue quand vous ouvrez « Récupérer », la base est interrogée quand vous touchez « Vérifier la configuration », et rien n'entre dans votre bibliothèque avant votre accord sur l'aperçu. Hors ligne, un envoi peut être mis en attente ; il ne part que lorsque vous touchez « Envoyer maintenant » (Réglages → Équipe).
                        • 
        
                      • Mise en place (une seule fois, par un seul musicien) : Réglages → Équipe → Configurer l'équipe… La fenêtre vous guide en quatre temps. 1. Créer le projet sur supabase.com (compte gratuit, plan Free). 2. Copier l'adresse du projet (Project URL) et la clé publique (Publishable key, sb_publishable_…), qui se trouvent sous le bouton Connect du projet ou dans Project Settings → API Keys, et les coller : le champ « tout coller d'un coup » reconnaît l'une et l'autre dans le bloc copié. 3. Générer le code d'équipe, puis lancer le script SQL affiché (« Copier le script », puis Supabase → SQL Editor → New query → coller → Run). 4. Vérifier la configuration : quatre contrôles (le projet répond, la clé est acceptée, le script est installé, le code est autorisé) et, pour celui qui échoue, ce qu'il faut corriger. Puis Enregistrer.
                        • 
        
                      • L'écran propose alors une invitation (QR code et lien) : les autres musiciens l'ouvrent (appareil photo, ou Réglages → Coller un lien) et confirment : adresse, clé et code se remplissent tout seuls, il ne reste qu'à indiquer son prénom (facultatif).
                        • 
        
                      • Quelle clé ? Seulement la clé publique (« Publishable key », ou l'ancienne clé « anon public »), faite pour être dans une page web. Jamais la clé secrète (sb_secret_… ou service_role) : elle donne tous les droits sur le projet. MusicApp la refuse, même collée par erreur, et ne la garde pas.
                        • 
        
                      • Envoyer un set : ouvrez la playlist, puis Outils → Envoyer cette playlist à l'équipe (ou « Envoyer à l'équipe… » dans Partager la playlist). Le nom du set, modifiable, l'identifie dans l'équipe. Si un set de ce nom existe déjà et que quelqu'un l'a modifié depuis votre dernier échange, un avertissement s'affiche avant de le remplacer ; changer le nom permet de garder les deux.
                        • 
        
                      • Récupérer un set : Outils → Récupérer un set de l'équipe (ou Réglages → Équipe → Récupérer un set…). Chaque set indique son auteur, son nombre de titres et sa date, et s'il est Nouveau, Modifié (depuis votre dernier échange) ou À jour. Un toucher ouvre l'aperçu d'import habituel : nouveau, déjà chez vous, différent.
                        • 
        
                      • Sans réseau : l'appli fonctionne comme avant. Envoyer ou récupérer demande une connexion ; un envoi impossible peut attendre dans Réglages → Équipe (il ne part que sur votre geste, avec « Envoyer maintenant »), et un set déjà récupéré reste dans votre bibliothèque. Si quelqu'un a modifié le set entre-temps, l'envoi en attente n'écrase rien : il est marqué « conflit ». Rouvrez la playlist et refaites Outils → Envoyer cette playlist à l'équipe : l'écran montre ce qui diffère et c'est vous qui décidez.
                        • 
        
                      • Ce que cela protège, et ce que cela ne protège pas. Le code d'équipe (16 signes tirés au hasard) est le seul secret : les tables de la base sont fermées à tout accès direct, seules quatre fonctions du script répondent, et chacune exige ce code. Il est impossible à deviner, mais quiconque reçoit l'invitation lit et écrit tous les sets du groupe ; il n'y a pas de comptes individuels. Ne la publiez pas ; si elle circule, créez une nouvelle équipe avec un nouveau code. Les sets sont stockés chez Supabase, non chiffrés : n'y mettez que ce que vous accepteriez de voir sur un serveur.
                        • 
        
                      • L'appli ne supprime jamais rien dans la base, et le script n'offre aucune fonction de suppression : pour retirer un set, Supabase → Table Editor → team_sets → supprimer la ligne. Pour retirer toute l'équipe (code perdu, invitation diffusée) : SQL Editor → delete from public.team_codes where code = '…'; (ses sets partent avec). Le « Security Advisor » de Supabase peut signaler les fonctions du script : c'est voulu, elles sont la seule porte d'entrée.
                        • 
        
                      • Limites : MusicApp doit être ouverte depuis son adresse https (depuis un fichier ouvert en local, cela dépend du navigateur) ; un set pèse au plus 900 Ko ; la liste montre les 500 sets les plus récents ; pas de synchronisation automatique ni d'historique des versions. Formule gratuite de Supabase : un projet resté une semaine sans activité est mis en pause (l'appli dit alors que le projet ne répond pas ; il se reprend en un clic dans le tableau de bord, et un envoi ou une lecture de temps en temps suffit à l'éviter), avec deux projets actifs et 500 Mo de base : très largement assez pour un groupe, mais ces conditions sont celles de Supabase et peuvent changer (supabase.com/pricing). Les réglages de l'équipe restent sur l'appareil : ni l'export, ni la sauvegarde Drive, ni les partages de fiche ne les contiennent. Chacun garde de toute façon ses playlists sur son appareil : la base de l'équipe sert à les échanger, pas à les sauvegarder.
                        • 
      
                      
      
                      Sans réseau et installation
                      
      
                        
        
                      • MusicApp n'envoie rien sur Internet de lui-même : chansons et playlists restent sur l'appareil, sauf ce que vous envoyez vous-même (Google Drive, Spotify, équipe : voir leurs sections). Pour l'utiliser sans réseau et l'installer comme une vraie application (icône, plein écran), elle doit être ouverte depuis son adresse https, avec le fichier sw.js posé à côté de index.html. Ouvrez-la une première fois avec Internet : elle se copie sur l'appareil, puis fonctionne partout, y compris dans une salle sans Wi-Fi.
                        • 
        
                      • Réglages → Hors ligne et installation dit si l'appareil est prêt (pastille verte). Vérifiez-le chez vous avant le concert : passez en mode avion et relancez l'appli pour en avoir le cœur net.
                        • 
        
                      • iPad / iPhone : Safari → Partager → Sur l'écran d'accueil. Android, Chrome, Edge : bouton « Installer MusicApp » dans les Réglages, ou menu du navigateur → Installer l'application.
                        • 
        
                      • L'appli installée a son propre espace de données, séparé de celui du navigateur : exportez vos données depuis le navigateur (Réglages → Exporter), puis importez le fichier dans l'appli installée. Installez avant de saisir de nouvelles chansons.
                        • 
        
                      • Mises à jour : une nouvelle version est téléchargée en coulisse et mise de côté ; un message propose « Recharger » et une pastille apparaît sur la roue dentée des Réglages. Tant que vous ne rechargez pas, la version que vous avez répétée reste celle qui sert : rien ne change tout seul, ni pendant un morceau ni au lancement suivant. Vos données ne sont jamais touchées par une mise à jour. Après avoir rechargé, fermez les anciens onglets ou fenêtres de l'appli.
                        • 
        
                      • Protéger mes données demande au navigateur de ne jamais effacer le stockage de l'appli, même si l'appareil manque de place. Safari peut effacer les données d'un site resté plusieurs jours sans être ouvert ; une appli installée sur l'écran d'accueil n'est pas concernée.
                        • 
      
                      
      
                      Importer des chansons
                      
      
                        
        
                      • Réglages → Importer (ou Outils → Recevoir une playlist) accepte un export EasyZic (.ezp), une sauvegarde MusicApp (.json), une playlist MusicApp partagée en fichier et une fiche ChordPro (.cho, .pro, .txt).
                        • 
        
                      • Un écran d'import liste chaque chanson du fichier avec son état : Nouvelle, Déjà chez vous (mêmes paroles et accords) ou Différente (même titre et même artiste, mais un autre texte). Décochez celles que vous ne voulez pas ; rien n'est ajouté avant « Ajouter la playlist » ou « Importer », et « Annuler » défait tout.
                        • 
        
                      • Pour chaque chanson différente, choisissez ligne par ligne : garder la mienne (par défaut), mettre à jour avec la version du fichier (votre titre, votre transposition, votre vitesse et vos instruments restent) ou garder les deux. Les trois boutons du haut règlent toutes les lignes d'un coup ; « Masquer les identiques » allège la liste d'un gros fichier.
                        • 
        
                      • Un export EasyZic ou un set reçu peut devenir une playlist (nom modifiable ; décochez la case pour n'ajouter que les chansons). Une sauvegarde permet de choisir aussi les playlists à recréer. Les chansons venues d'EasyZic ou d'une sauvegarde gardent leur vitesse (et, pour une sauvegarde, leur transposition) ; celles d'un set reçu repartent de vos réglages.
                        • 
        
                      • « Tout remplacer… » (sauvegarde seulement) remet chansons, playlists et réglages exactement dans l'état du fichier, après confirmation. Sur une appli neuve, la restauration est directe.
                        • 
        
                      • Une fiche ChordPro inconnue est ajoutée tout de suite ; si une fiche de même titre existe déjà, l'écran d'import vous laisse choisir (identique : rien n'est ajouté).
                        • 
      
                      
      
                      Sauvegarde
                      
      
                        
        
                      • Les données restent dans ce navigateur : exportez-les régulièrement depuis les Réglages (.json). Les fichiers EasyZic (.ezp), ChordPro (.cho, .pro, .txt) et les playlists MusicApp partagées en fichier peuvent être importés (voir « Importer des chansons »).
                        • 
        
                      • La bibliothèque est gardée dans une base du navigateur (sans la limite d'environ 5 Mo de l'ancien stockage) et recopiée aussitôt à chaque modification dans le stockage habituel. Si la bibliothèque change dans une fenêtre, les autres fenêtres ouvertes sur le même appareil reprennent la dernière version au lieu de l'écraser plus tard.
                        • 
        
                      • Le texte que vous êtes en train d'écrire dans l'éditeur est copié comme brouillon : si la page se ferme brutalement, un message « Brouillon retrouvé » propose de le reprendre à la prochaine ouverture. Enregistrer la chanson efface le brouillon ; quitter sans enregistrer aussi, mais le message « Modifications abandonnées » propose alors de Rétablir.
